Pair this device

This console controls a real lamp, so it only talks to paired devices. Reading the lamp and changing it both need pairing.

On the computer running govee serve, run:

govee token new --name <label>

Then open the printed link on this device. It pairs the browser and drops the token from the address bar.

    Agents

    Any Claude-backed agent in the mesh can use the lamp through the govee MCP server. The same rules apply to agents, the command line and this page.

    MCP tools

    Served over stdio by govee mcp serve

    • list_devicesread

      Lamps found on the LAN and in the Govee account, with model and transport.

    • get_stateread

      Power, brightness, color or color temperature of one lamp.

    • set_lightdry run unless apply

      Power, brightness, color, color temperature. Returns the exact command it sent or would send.

    • set_scenedry run unless apply

      Applies one of the lamp's scenes through the cloud API.

    • get_statsread

      On-time, brightness and command counts over a time range.

    Mesh rules

    Enforced by the server, so a prompt cannot talk an agent past them

    • Dry run by default

      A write without apply: true returns the command it would send and changes nothing.

    • Every call is logged

      Each write records its source (CLI, web, MCP or rules) and who made it, and shows up in Stats.

    • The key stays in the environment

      Agents never see GOVEE_API_KEY. The server reads it and never echoes it.

    • Schedules live in culture-rules

      govee has no timers of its own. A culture-rules rule calls the govee runner actor, for example lamp_color when CI fails.
